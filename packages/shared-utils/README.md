# @yardinternet/shared-utils

Shared utilities used internally by `@yardinternet/toolkit` and `@yardinternet/vite-config`.

## Usage

```js
import { resolveThemeContext, getAllThemeNames } from '@yardinternet/shared-utils';
```

## Contents

- **Theme context** (`resolveThemeContext`, `getAllThemeNames`) — theme discovery for brave-root / theme-root project layouts.
